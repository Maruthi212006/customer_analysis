
# Customer Purchase Frequency Analysis

## Project Overview
Customer Purchase Frequency Analysis is a Python-based
data analytics project that analyzes customer purchasing
behavior and identifies frequent, occasional, and
low-frequency customers.

## Objectives
- Analyze customer purchase frequency.
- Calculate total customer spending.
- Calculate average purchase amount.
- Identify frequent customers.
- Visualize customer buying patterns.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Project Structure

Customer-Purchase-Frequency-Analysis/
- customer_analysis.py
- dataset.csv
- requirements.txt
- README.md

## Features
1. Customer purchase frequency calculation.
2. Total spending calculation.
3. Average purchase amount calculation.
4. Customer classification.
5. Purchase frequency visualization.
6. Customer spending visualization.
7. Export analysis results to CSV.

## Installation

Install Python on your computer.

Install the required libraries:

pip install -r requirements.txt

## How to Run

Open the project folder in VS Code.

Run this command:

python customer_analysis.py

## Output
- Customer purchase analysis.
- Customer frequency chart.
- Customer spending chart.
- customer_analysis_output.csv

## Conclusion
This project helps businesses understand
customer purchasing patterns and improve
customer retention strategies.
